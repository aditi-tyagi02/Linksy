## Overview

Linksy takes long, unwieldy URLs and turns them into short, shareable links — with the option to choose a custom, memorable alias instead of a random code. Every shortened link can also be turned into a scannable QR code, downloadable as a PNG.

This project was built to demonstrate practical full-stack development skills: designing a REST API, modeling relational data, building a reactive frontend, and thinking through real product details like input validation, live availability checks, and UI states (loading, error, empty).

---

## Features

- **URL Shortening** — Convert any long URL into a short, unique link
- **Custom Aliases** — Choose a memorable slug (e.g. `linksy/my-portfolio`) instead of a random code, with live availability checking as you type
- **QR Code Generation** — Every short link can generate a scannable QR code, downloadable directly to your device
- **Click Tracking** — Each link tracks how many times it's been visited
- **Input Validation** — Both client- and server-side validation for URLs and aliases, with clear, human-readable error messages
- **Responsive, Modern UI** — Clean dark-themed interface built with Tailwind CSS, designed to feel like a real SaaS product rather than a tutorial project

## Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | FastAPI (Python) |
| **Database ORM** | SQLAlchemy |
| **Database** | SQLite (local) |
| **Frontend** | React (Vite) |
| **Styling** | Tailwind CSS |
| **QR Generation** | `qrcode` (Python) |

### Why these choices?
- **FastAPI** was chosen for its speed, automatic OpenAPI/Swagger documentation, and modern async-first design — increasingly common in production backend systems.
- **SQLAlchemy** provides a clean ORM layer over raw SQL, making the data model easy to reason about and extend.
- **React + Vite** offers a fast development experience and is the most widely used frontend stack in the industry.
- **Tailwind CSS** enables rapid, consistent UI development without writing custom CSS from scratch.

```
                                                   ▼
                                            ┌──────────────┐
                                            │   SQLite     │
                                            │   Database   │
                                            └──────────────┘
```

**API Endpoints:**

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/shorten` | Create a short URL (with optional custom alias) |
| `GET` | `/{short_code}` | Redirect to the original URL, increments click count |
| `GET` | `/stats/{short_code}` | Get click stats for a short URL |
| `GET` | `/check-alias/{alias}` | Check if a custom alias is available |
| `GET` | `/qrcode/{short_code}` | Generate and return a QR code image (PNG) |

Full interactive API documentation is auto-generated by FastAPI and available at `/docs` when running the backend locally.

## Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+

### 1. Clone the repository

```bash
git clone https://github.com/aditi-tyagi02/Linksy.git
cd Linksy
```

### 2. Backend setup

```bash
cd backend
python3 -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
uvicorn main:app --reload
```

The backend will run at `http://127.0.0.1:8000`. Visit `http://127.0.0.1:8000/docs` for interactive API documentation.

### 3. Frontend setup

Open a new terminal:

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

The frontend will run at `http://localhost:5173`.

### 4. Use the app

Open `http://localhost:5173` in your browser, paste a long URL, optionally add a custom alias, and click **Shorten**.
